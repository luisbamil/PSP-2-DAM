# 🧵 Concurrencia y sincronización en Java — 2º DAM · PSP

Bienvenidos al repositorio oficial de ejemplos prácticos para la asignatura de **Programación de Servicios y Procesos (PSP)**, impartida en **2º curso del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM)**.

Aquí encontrarás una colección de ejercicios y demostraciones sobre:

- ✅ Creación de hilos con `Thread` y `Runnable`
- ✅ Gestión profesional de tareas con `ExecutorService`
- ✅ Coordinación entre hilos con `wait()`, `notify()` y `notifyAll()`
- ✅ Sincronización con `synchronized` y prevención de condiciones de carrera
- ✅ Diagramas explicativos y ejemplos visuales para reforzar la teoría

Todos los ejemplos están diseñados para ser **claros, comentados y ejecutables** en el entorno de desarrollo **Eclipse IDE**, que será el compilador y entorno oficial utilizado en clase. Se recomienda importar cada carpeta como un proyecto Java independiente o agruparlos en un único workspace para facilitar la navegación.

---

## 🎯 Objetivo del repositorio

Este repositorio tiene como finalidad:

- Servir de apoyo visual y práctico a los contenidos teóricos del módulo PSP.
- Fomentar el aprendizaje autónomo mediante ejemplos ejecutables y modificables.
- Proporcionar una base sólida para entender la programación concurrente en Java, una habilidad clave en el desarrollo de software moderno.

---

## 🧪 ¿Cómo ejecutar los ejemplos?

1. Clona o descarga el repositorio.
2. Abre Eclipse IDE y selecciona **File → Import → Existing Projects into Workspace**.
3. Ejecuta los archivos `.java` desde el método `main()` de cada clase.
4. Observa el comportamiento de los hilos en consola y experimenta modificando los valores.
